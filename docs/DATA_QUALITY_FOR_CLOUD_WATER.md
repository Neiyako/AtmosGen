# 合成数据在云水资源量计算中的可用性边界

> 面向云水资源量（凝结量、水汽通量辐合 MFC 等）下游计算，评估 AtmosGen 当前三种生成模式产出的合成数据**能否支撑论文级精度要求**。
> 结论先行：**不能**——边缘分布几乎一致，但云水资源量是**导数型量**，合成数据在导数运算后与真实场完全不相关（图案 r ≈ 0），
> 而量级却与真实相当（"看着像、逐格全错"）。本文件给出机理、实测数据、可写进论文的结论与改造路线。
>
> 全部数字可复算：`python scripts/quality_fidelity.py --real data/processed/era5_local.nc --runs <生成的数据.nc …]`
> （产物：`output/quality_fidelity/report.json` + `report.md` + `figures/`）。

---

## 1. 为什么"边缘分布好"不等于"云水资源量可用"

云水资源量的主流算法都建立在一组**导数型运算**上：

| 算法 | 形式 | 对数据的敏感点 |
|---|---|---|
| 水汽通量辐合法（MFC） | `MFC = -∇·(q·V)`，垂直多层积分 | 水平**散度** + 垂直**积分** |
| 凝结-降水差法 | `R = P_cond - P_evap`，由比湿剖面诊断凝结高度 | 垂直**梯度**、层间**差分** |
| 温度-露点差法 | 假绝热抬升 → 凝结高度 → 凝结量 | 层间**插值**与**差分** |
| 水汽收支法 | `∂W/∂t + ∇·(qV) = S` | 时间**累积** + 水平散度 |

这些量对"相邻格点/相邻层/相邻时刻之间的相关性"极其敏感，而单表合成模型（SDV 类）建模的是
**格点值的联合分布**，天然不承诺时空协方差（项目计划 §4.1、风险 X2 已明确写入）。

机理可以用噪声放大说清：对一个**空间上互不相关**的场求散度，噪声被差分算子放大到与真实信号同量级；
而边缘分布（直方图、KS）**完全看不出**这件事。于是合成数据在"看起来正常"的表象下给出错误的辐合区/辐散区。

## 2. 实测（真实 ERA5 切片 vs 合成数据；同一算子、同一网格）

真实参考：`data/processed/era5_local.nc`（2010-05-01..04，16 时次 × 3 层 × 101×101，t/q/u/v + 派生 tcwv）；
合成：1° 抽稀网格 26×26；MFC 用 500/700/850 三层平均水汽通量的水平散度。

| 数据集 | KS(t) | KS(q) | 时序相关 r | 空间图案 r | ACF1 真实/生成 | 饱和违例 | **MFC 图案 r** | **MFC 幅度比** | MFC 域总量比 |
|---|---|---|---|---|---|---|---|---|---|
| statistical (copula) | **0.031** | **0.027** | −0.197 | 0.009 | 0.890 / −0.260 | 3.29% | **+0.002** | 0.885 | 0.161 |
| statistical (ctgan) | 0.059 | 0.091 | 0.316 | 0.054 | 0.890 / 0.141 | 10.39% | +0.021 | 0.967 | 0.200 |
| statistical (tvae) | 0.034 | 0.029 | 0.198 | 0.020 | 0.890 / −0.531 | 0.36% | −0.066 | 0.736 | 0.064 |
| hybrid（物理基底+条件生成+筛检） | 0.051 | 0.109 | −0.214 | **0.578** | 0.942 / −0.057 | **0.00%** | +0.038 | 1.065 | −6.31 |
| physics（advection–diffusion） | n/a | n/a | n/a | n/a | n/a | n/a | n/a | n/a | n/a |

**读这张表**：

1. **边缘几乎一致**：KS(t)=0.031、KS(q)=0.027 —— 直方图/KS 检验会判定"数据质量很好"。
2. **导数型量完全失效**：MFC 图案相关 r=+0.002（≈0），即**逐格对照全错**；但 MFC 空间幅度比 0.885，
   即"量级看起来正常"。这是最危险的情形：肉眼或量级检查都不会发现错误。
3. **时间持续性丢失**：真实 lag-1 ACF=0.890（天气过程有持续性），生成序列 ACF1 为 −0.26 / −0.53
   （独立采样，甚至轻微反相关）→ **年际变化、极端事件频次、持续性过程全部不可用**。
4. **空间结构**：统计生成的空间图案相关仅 0.009–0.054；混合模式靠物理基底恢复到 0.578，
   说明**物理基底确实注入空间结构**，但时间结构仍未恢复（逐场输运 + 逐格点条件采样）。
5. **物理自洽**：混合模式筛检后饱和违例 0%（筛除 653/32448 = 2.01%），而统计模式有 0.36%–10.39% 的超饱和组合。
6. **域总量比 0.06–0.20**：连"总量级"也不对（域平均辐合被噪声部分抵消），说明不是"格局错但总量对"。

## 3. 对论文证据链的逐条判定

| 论文需要的证据 | 用合成数据能否支撑 | 依据（上表） |
|---|---|---|
| 云水资源量的**空间格局**（辐合区/辐散区、水汽源汇） | ❌ | MFC 图案 r ≈ 0.00–0.04 |
| 云水资源量的**量级**（与站点/文献对比） | ❌ | 域总量比 0.06–0.20；MFC 幅度虽是 0.7–1.1×，但那是噪声幅度 |
| **年际变化 / 极端事件** | ❌ | ACF1 真实 0.890 → 生成 ≤ 0.141 |
| **多算法对比 + 不确定性** | ❌ | 噪声主导，方法间差异被淹没 |
| **数据缺测/稀疏场景的补全可行性** | ⚠️ 需要新方法 | 当前模式不建模时空协方差，补出来的值无物理一致性 |
| **方法学/工程链路**（契约、QC、可复现、不确定性传播框架） | ✅ | 见 §4 |
| **合成数据可用性边界本身**（作为结论章节） | ✅ | 本文件即证据 |

## 4. 建议的论文用法

### 路线 1（推荐给本科毕设/硕士主线）：真实数据算资源量，合成数据做方法学支撑
1. 用 AtmosGen 的契约/IO/验证层承载**真实 ERA5**：ingest → 契约化 → QC（四类验证 + 阈值）→ 计算 MFC / 凝结-降水差 / 温度露点差；
2. 与站点观测、文献值对比，做量级 + 格局 + 不确定性分析（论文主体）；
3. 合成模式用于**敏感性/压力测试**：采样不确定性、缺测敏感性如何传导到资源量估计；
   或作为"数据增强在缺测区是否可行"的**否定性结论**（用本文件的指标体系支撑）。

### 路线 2（方法研究向）：把"合成数据可用性边界"做成结论
- 用 §2 的指标体系 + `scripts/quality_fidelity.py` 形成可复现的方法学章节：
  **"边缘分布相似 ≠ 导数型下游量可用"**，并给出判据（KS + MFC 图案 r + ACF1 三件套）。
- 这在合成数据/数据增广类论文里是很有价值的**审慎结论**，且能直接引本仓库的复现脚本。

### 路线 3（工程改造向）：让合成数据真的能算资源量
按性价比排序：

| 改造 | 做法 | 目标指标 | 成本 |
|---|---|---|---|
| **通量保持生成** | 先生成水汽通量场 `F=q·V` 的真实统计特征（幅度、谱、相关性），再反解 `q=F/V`（或直接生成 F 并约束 q 的边缘） | MFC 图案 r 从 0.00 → >0.5 | 中 |
| **时空条件生成** | 把 hour/lat/lon 纳入条件采样，并解决 Phase 2 实测的边界退化（分位数空间/条件 copula/条件 GAN） | 空间图案 r >0.5、ACF1 >0.5 | 高 |
| **水汽收支物理模式** | 把求解器扩展为真实 u/v 驱动的湿空气输运 + 凝结/降水参数化，输出真正的气象要素场 | 可直接算资源量 | 高 |

> 混合模式已证明"物理基底能注入空间结构（0.009→0.578）"，因此路线 3 的第一条是**最现实的下一步**。

## 6. 术语与口径

- **KS**：两样本 Kolmogorov–Smirnov 统计量（边缘分布距离，0 = 完全一致）。
- **时序相关 r**：同一格点、同一层的真实与生成时间序列的 Pearson 相关。
- **空间图案 r**：同一时刻、同一层，真实与生成场的空间距阵相关（衡量天气系统结构）。
- **ACF1**：lag-1 自相关（衡量持续性）；真实 ERA5 区域 500 hPa 温度 ≈ 0.89。
- **MFC**：水汽通量辐合 `−∇·(q·V)`；本诊断用 500/700/850 三层平均水汽通量的水平散度近似（同一算子用于真实与生成，可比）。
- **饱和违例**：`q > 1.10 × q_sat(t, p)`（Tetens 饱和比，plan §5.4 硬约束）。
